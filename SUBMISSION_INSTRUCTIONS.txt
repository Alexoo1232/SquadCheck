SquadCheck startup instructions

How to run the project:

1. Extract the ZIP file.
2. Open SquadCheck.slnx in Visual Studio.
3. Make sure the .NET SDK is installed.
4. Press F5 or click the green run button in Visual Studio.

Alternative terminal command:

dotnet run

Then open the local URL shown in the terminal.

Included data:

This submission includes the current local application data.
The data is stored in:

App_Data/squadCheckData.json

The file contains saved users, groups, practice sessions, and attendance records.
If the file is deleted, the application can create a new empty data file when new data is saved.

Basic use:

1. Open the Groups page to view or create groups.
2. Open a group to add members or create practices.
3. Open the Practices page to view practice sessions.
4. Open a practice session to mark attendance and view the attendance summary.
